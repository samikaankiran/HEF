# HEF — hef.com.tr

Static website for HEF, a design and fit-out studio in Istanbul.
Designed and built by [Workattack](https://www.workattack.com).

- Plain HTML/CSS/JS, no build step.
- Hosted on Vercel; `404.html` is the not-found page.
- `.htaccess` is only used if the site is served from Apache hosting.
